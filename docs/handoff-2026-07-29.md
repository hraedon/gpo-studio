## The one thing to understand before planning

**Evidence is the binding constraint, not code.** Every time an external oracle
has read this codebase it has found the code disagreeing with Windows:

| Lane | Finding | Correction |
|---|---|---|
| WP-3 | `security_template.py` emitted output that was not valid MS-GPSB on the wire at all | +36 −1 |
| WP-1B | `gpp_adapters`, `ilt`, `gpp`, `policy_config` — **surfaced code shipped in 1.0** | +547 −58 |

`docs/domain-layer-status.md` states the strength of that evidence precisely:
direct evidence for the unsurfaced set is n=1, the rest is inference by
analogy. Enough to stop counting landed layers as progress; not enough to say
what specifically is broken in any layer no oracle has read. Hence lanes, not
audits.

Practical consequence: **do not plan breadth-first platform wiring of Plans
025–032.** Expect each evidence lane to rewrite the serialization it touches.

## Open work, in priority order

### 1. Unattended OS installation (next execution step)

The estate has VM shells only. `windows-evidence-lab/docs/estate-topology.md`
defines the remaining slices. Answer-file injection was deliberately *not*
folded into the build script: half-automating it yields a script that looks
idempotent, reports success, and leaves guests inconsistent.

Two constraints that will bite if missed:

- **Install Server with Desktop Experience, not Core.** The media offers both.
  The WP-1B manual GPMC edit/save leg needs a GUI on the member server.
- **`LabDC01` must own time.** Its Hyper-V time-sync integration service is
  already disabled by the build script; keep it that way and make the DC
  authoritative. A VMIC source fighting a DC clock is what made new gMSAs
  unusable in the operator's other forest.

Then: promote the forest, join member and client, take clean checkpoints.

### 2. Move the orchestrator to PowerShell Direct

The harness currently SSHes straight to its target. The estate has **no guest
networking at all** — by design, since PowerShell Direct reaches guests through
the hypervisor. The path becomes: controller → SSH to lab host → PS Direct →
guests. Keep the scheduled-task launcher in `remote-run.ps1`; PS Direct still
cannot delegate credentials to AD.

### 3. WP-6, the endpoint lane — first lane on the new estate

Chosen as first because it is the only lane that can settle **Finding
WP-1B-1**: Studio writes Task Scheduler 1.0 scalar attributes onto a `TaskV2`
element, and GPMC's report echoes them straight back, so no round trip can ever
detect it. Only a CSE actually processing the task resolves it. Secondary
payoff: the first ever comparison of `rsop.py` predictions against real
`gpresult` output.

**Its finalizer must assert a real `client_build`.** The `not-tested` sentinel
is on-target at the parser level because the parser cannot tell which lane
produced a manifest; a client-touching lane must not claim endpoint evidence it
did not gather. Land that assertion in the same change as the lane.

### 4. Re-pointing lanes at the estate

The five lane scripts read `GPO_STUDIO_ORACLE_HOST`, defaulting to the historic
shared host. **Re-pointing is not a variable change**: every certification is
bound to the environment recorded in its own manifest, so moving a lane
requires a fresh qualification run and a re-freeze of `environment-spec.md`.
The first lane certified on the estate starts from zero and inherits nothing.

## Traps this session paid for

Each of these cost real time; they are written down so they cost it once.

- **`-CheckOnly` on a greenfield host proves less than it appears to.** With no
  VM to inspect it reports the create actions and stops, never reaching the
  attach/sizing/firmware branches. A StrictMode defect passed a clean check run
  and then failed the apply.
- **StrictMode Latest throws on member access over an empty array.**
  `@(Get-VMHardDiskDrive ...).Path` fails on a VM with no disks. Project with
  `ForEach-Object`, which is safe on empty.
- **Never `git add -A` in these repos.** A concurrent session's uncommitted
  work gets committed under your authorship. It happened twice today, and both
  times meant committing files that had never been read. Stage by explicit path
  and check `git diff --cached --name-only`.
- **Squash-merge orphans commits.** Anything citing a branch SHA in committed
  documentation dangles after merge. Cite the PR and the merged commit.
- **Verify numbers before writing them in prose.** A PR body claimed a
  readiness split the committed data contradicted, in a PR whose subject was
  not taking things on trust.

## Conventions worth knowing

- `AGENTS.md` carries the standing rules; read it first.
- Never run `ruff format src/` — the repo is not ruff-format-clean and it
  rewrites 50+ unrelated files.
- `scripts/check_safety.py` forbids `ET.fromstring`; use `parse_xml_bounded`.
- The identifier gate is secret-driven and skips locally when
  `GPO_STUDIO_FORBIDDEN_IDENTIFIERS` is unset. It runs for real in CI.
- `windows-evidence-lab` commits **no hostnames and no domain names** — stricter
  than this repo. Host, forest, and media arrive as parameters.
