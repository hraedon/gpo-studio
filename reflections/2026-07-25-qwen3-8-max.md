## On the project

The frozen-dataclass + JSON-snapshot-store + optimistic-concurrency architecture
continues to scale remarkably well. Every new module (SOM, RSOP, delegation,
publisher, hosting) slots into the same pattern without requiring architectural
changes. The `assert_never` charter rule caught real bugs: when WP-4 added 10
new ILT predicate types, the `assert_never` in validation.py immediately flagged
all 10 unhandled sites, forcing correct handling before any test could pass.

The subagent-driven workflow was highly effective for plan-driven work. Each
tranche had a clear spec, the implementer agents followed conventions well, and
the adversarial review of WP-2 caught 4 critical bugs (site link block_inheritance,
silent parent truncation, misleading warnings, link scope_dn mismatch) that
synthetic tests missed. The most productive pattern was: implement → adversarial
review → fix → verify. Alternating implementer and adversarial reviewers
conserved adversarial budget while maintaining quality.
